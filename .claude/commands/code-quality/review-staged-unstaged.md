# Review Staged/Unstaged with Archon & Serena

Review git changes against YOUR documentation and patterns.

## Process

1. **Show changes:** `git diff --staged` and `git diff`

2. **Query Archon:** "Get coding standards for [language]"

3. **Use Serena:** "Find similar changes in project history"

4. **Validate:**
   - Against Archon best practices
   - Against Serena patterns
   - For consistency with project

5. **Report issues** with references to Archon docs and Serena patterns
